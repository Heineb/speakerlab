# SpeakerLab Branding

SpeakerLab is the product and project name in UI owned by this repository. Its temporary identity uses a neutral geometric speaker mark, restrained monochrome treatment, whitespace and the existing calm interface hierarchy. The mark is deliberately replaceable and does not imitate Bang & Olufsen artwork.

## Canonical assets

`Beocreate2/beo-system/common/speakerlab-mark.svg` is the canonical product mark for the browser shell, manifest, setup and README. `Beocreate2/beo-system/common/speakerlab-wait-animate.svg` is its loading-state companion.

`Beocreate2/beo-extensions/product-information/symbols-black/speakerlab-mark.svg` is an intentional monochrome UI-symbol adaptation, not a second brand source. Its extension-local path and black mask treatment are required by the inherited menu icon loader.

`docs/assets/speakerlab-social-preview.svg` and its rendered PNG are repository presentation assets derived from the same geometry. The PNG is ready for manual upload under GitHub repository **Settings → General → Social preview**. GitHub repository metadata is not controlled from this repository.

Use SpeakerLab for the browser title, web-app manifest, setup identity, loading state, default project-owned product identity, About heading and new feature documentation. Do not add a separate decorative brand layer or redesign established navigation.

Keep Beocreate and Bang & Olufsen references when they identify the current Beocreate 4-Channel Amplifier, the `beocreate` WebSocket/service contract, inherited paths or package names, original speaker products, upstream history, copyright, licence or source provenance. These are attribution and compatibility facts, not SpeakerLab branding.

Every user-visible slice should check its changed UI, metadata, assets and documentation for stale project branding. Replace only project-owned presentation; never erase required notices or rename compatibility interfaces incidentally.
